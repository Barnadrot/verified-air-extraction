# Arithmetic, decoder and binding proofs

Start with the [root README](../../README.md) and the
[proof walkthrough](../../docs/walkthrough.md). Start the arithmetic
review at `DivRemFV/Statement.lean` and the artifact review at
`DivRemFV/ExtractorBinding.lean`. `StatementAudit.lean` and `ReplayAudit.lean`
list the required axiom-audit endpoints.

Run `bash build.sh --stage main` from the repository root after bootstrap.
`artifacts/` and `.lake/` are generated and excluded from version control.
